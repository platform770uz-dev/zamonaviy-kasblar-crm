# Zamonaviy Kasb — кандидатский сайт

Публичный двуязычный сайт-визитка вакансии B2B-представителя. Проходит путь: условия → короткая анкета → 3 урока → тест из 5 вопросов → результат и согласие → сохранение заявки в CRM.

## CRM

Форма вызывает Supabase Edge Function `vacancy-assessment`. Функция пересчитывает ответы на сервере и записывает контакты, город, водительские права, автомобиль и топливо, график, ответы и оценки в `meta_admin_leads`. Существующий CRM показывает эту таблицу только руководителю; карточка заявки помечена источником сайта в `meta_answers`.

В публичную страницу не помещается серверный ключ. Edge Function использует серверную переменную `SUPABASE_SERVICE_ROLE_KEY`; для публичной отправки JWT-проверка функции отключается, а обработчик проверяет Origin, поля, согласие, ответы и размер запроса.

## Публикация

Страница предназначена для пути `/zamonaviy-kasblar-crm/vakansiya/` на GitHub Pages аккаунта `platform770uz-dev`. Если страница будет опубликована из отдельного репозитория, меняется только URL сайта; разрешённый Origin функции остаётся `https://platform770uz-dev.github.io`.

Функция ограничивает частоту заявок с одного IP до 8 в час. Для этого нужен SQL из `backend/vacancy_submission_rate_limit.sql`; в таблице хранится только SHA-256 от адреса, а не сам адрес.
